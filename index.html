DeviceLink 📱⇄🖥

Live screen, touch, camera, apps — apne Android ko browser se control karo. Zero install on the computer, ek APK on the phone. LAN-only prototype.

  1. Phone pe DeviceLink APK install karo (MIUI: “Install unknown apps” allow). ⬇ Download APK
  2. App kholo → Start screen streaming → Allow now, phir step 2 ka Accessibility toggle ON karo.
